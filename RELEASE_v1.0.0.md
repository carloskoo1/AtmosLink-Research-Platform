---

# Overview

AtmosLink Research Platform is an integrated scientific platform developed for continuous acquisition, storage, synchronization, validation and analysis of meteorological variables and wireless radio-link telemetry in high-altitude rural environments.

Version 1.0.0 represents the first stable software baseline prepared for the Cuñacales–San José experimental field campaign.

---

# Main Components

- Local meteorological acquisition
- SQLite scientific database
- ERA5-Land integration
- NASA POWER integration
- Scientific dataset enrichment
- Web dashboard
- Central scheduler
- Scientific health monitor
- Google Drive verified backup
- Backup concurrency protection
- Radio telemetry framework
- Operational state management
