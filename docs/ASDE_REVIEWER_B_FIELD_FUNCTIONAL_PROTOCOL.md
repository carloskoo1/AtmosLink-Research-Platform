**Status:** written before reading throughput or RF values for the 6475 MHz / 20 MHz cohort. Post-audit study; no natural candidate is promoted and D_validation (7000/20) stays reserved.
**Purpose:** ask whether direction-specific analog RF telemetry (RSSI/SNR) covaries with independently measured TCP goodput in a later configuration episode on the *same physical link*. This can corroborate functional relevance, but cannot identify a propagation mechanism, validate the six-field MCS encoding, or establish cross-link transportability.

## Frozen analysis

1. Read only the named cohort, using `usecols` to exclude raw iperf JSON and weather. Verify source hash before analysis. Eligible row: 6475 MHz / 20 MHz, `status=OK`, `protocol=TCP`, `route_verified=1`, duration exactly 8 s, one stream, recorded AP/SM powers 10/3 dBm, absolute RF/test offset <=300 s, positive finite measured goodput, finite RSSI and SNR for the same direction. Do not interpolate, impute, or trim outliers. Report counts and exclusion reasons.
2. Within the eligible cohort, calculate a *direction-specific* analog quality score `q=(z_RSSI+z_SNR)/2`. Reference each feature to its cohort median and robust scale `1.4826*MAD`, falling back to `IQR/1.349`, then population SD, then 1, exactly as in the existing detector. This unsupervised calibration never uses goodput. Lower q means weaker analog RF telemetry.
3. For DL and UL separately, report Spearman rank correlation between q and measured goodput; median goodput in bottom and top score quartiles using q <= empirical Q1 and q >= Q3 (ties retained); their absolute difference (top minus bottom) and ratio (bottom/top). Also report the same summaries by UTC day when >=20 eligible tests per direction, without selecting favorable days.
4. Calculate the corresponding direction-matched summaries on the 7000/20 D_development interval only, using that interval's own analog median/scale. This comparison is descriptive and post-audit. No D_validation RF/goodput values are read or analyzed. Report distinct time/configuration windows and the overlap of raw test records with the benchmark source.
5. Primary interpretation is directional consistency across the two episodes: positive q–goodput correlations and positive top-minus-bottom quartile differences in *both* directions and episodes support a limited functional association. Zero/negative directions count against this corroboration. No formal p-value or confidence interval is used: serially dependent tests on one link and four calendar days do not provide independent field replication. TCP goodput includes traffic/test/transport effects and is not path attenuation or availability.
6. Preserve all numbers, eligibility counts, exact source/protocol/code hashes, and a fixed result JSON. Results must not redefine a natural RF-degradation threshold or retroactively alter v21/v23/v25 benchmark endpoints. B closes only if the manuscript's RF claims are explicitly bounded to operational telemetry and any remaining empirical result supports that scope; a strong goodput association cannot by itself close mechanism, MCS semantics, or cross-link limitations.
