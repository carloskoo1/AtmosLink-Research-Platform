# Reviewer B — RF/telecommunications audit

**Date:** 2026-09-26. **Disposition:** **OPEN (Major)**. The primary synthetic benchmark is an algorithmic perturbation of telemetry; it is not yet a physically calibrated model of a 6 GHz radio fade. Only D_development rows were analyzed and reported; D_validation values were not used for claims or tuning. The read-only source-export join loaded selected columns from the larger export before restricting the calculation to exact development timestamps, so a claim that its bytes were never accessed would be inaccurate. External cohorts were not analyzed.

## Reproduced evidence

- Source: `Results/scientific_discovery/DISCOVERY-001/prevalidation_7000_20.csv` (2,860 rows, 2026-09-01 18:30:52 to 2026-09-13 03:29:49 UTC). Every row reports 7000 MHz / 20 MHz; the 17-column analysis snapshot contains six RF metrics, seven local weather metrics, timestamp, configuration, and validity flag. The larger integrated campaign export also contains power, reported link rates and TX indicators; these were excluded from the benchmark snapshot.
- `scientific_discovery/synthetic_benchmark.py`: quality is the arithmetic mean of six separately standardized RSSI/SNR/MCS columns. The injected signal subtracts `effect_sd * scale` from **all six columns** for three 5-min bins at registered lags; this deliberately matches the composite detector's sign and morphology.
- DL MCS observed codes: 103, 104, 106, 109, 201–206; UL MCS: 101–104, 200–203. The collector copies the raw `connectedSTADLMCS`/`connectedSTAULMCS` fields without decoding. The exact 1xx/2xx semantics for this 4600-series export have not been independently verified against its firmware schema. The vendor datasheet describes adaptive MCS 0–13, so 101/204 must not be assumed to be linear physical MCS values.
- The robust reference falls back to ordinary standard deviation when both MAD and IQR are zero. DL MCS median 204, MAD and IQR zero, fallback scale **5.893997**; UL MCS median 202 and scale **1.4826**. The DL scale is affected by rare 1xx codes; ordinary adjacent 203/204 changes are one code unit, while family changes are about 100.
- At the registered 1.0-SD injection, DL code 204 becomes **198.106003** and UL code 202 becomes **200.5174**. Every injected MCS value is fractional if the original is an integer. Some DL 1xx codes become values below 100. These are mathematical values outside the observed integer telemetry encoding, not valid simulated radio states.
- First differences of DL RSSI and DL SNR correlate 0.75, UL RSSI and UL SNR 0.48, but DL versus UL analog correlations are about 0.07–0.11 and MCS differences correlate roughly 0–0.04 with RSSI/SNR differences. A simultaneous six-variable reduction is a targeted stressor rather than an empirically typical joint event.
- The existing v15 morphology stress reports much lower 1-SD recovery for RSSI-only, SNR-only and MCS-only perturbations (0.74/0.50/0.08 at 15/30/60 min). Existing v16 outcome sensitivity changes the exploratory CTX-0001 conclusion under DL-only versus other definitions.
- A read-only join of all 2,860 development timestamps to `Data/exports/scientific_campaign_6g_integrated.csv` (SHA-256 at audit: `389792038327c9b6a65ddceaa32452d6bf272abdddfb8202dc36f96687290bf3`) found AP Tx 10 dBm in 2,860 rows, SM Tx 3 dBm in 2,858, dual-link status in 2,858, DL reported link rate in 2,860, and UL reported link rate in none. DL code 204 occurs in 2,553 rows with 103 Mbps reported in every such row; rare 1xx codes have differing reported rates. This is empirical code/rate correspondence, not a vendor-verified mapping.
- Frozen post-audit analog stress protocol: `docs/ASDE_REVIEWER_B_ANALOG_STRESS_PROTOCOL.md` at commit `35623bc`; runner `scripts/run_asde_v25_reviewer_b_analog_stress.py`; results `Results/scientific_discovery/DISCOVERY-001/v25_reviewer_b_analog_stress/`. The same development background and four drivers are reused, with new seeds. Only the designated RSSI/SNR direction is reduced by 2 dB for 15 min, retaining MCS as observed; BOTH, DL, and UL outcomes are recalibrated separately. This is a numerically admissible stress, not a physical channel simulator.
- Matched morphology/outcome exact-driver selection over 400 conditional trials per lag: BOTH/BOTH 0.685/0.7825/0.100; DL/DL 0.5175/0.855/0.130; UL/UL 0.615/0.7375/0.230 for 15/30/60 min. Under DL-only injection, the shared BOTH detector selected at 0.685/0.7125/0.0325; under UL-only injection at 0.650/0.5525/0.030. Cross-direction views had zero truth selections. Response at 60 min remained poor, and pooling hides strong driver heterogeneity.
- Circular-shift surrogate-null selection on the fixed background was 19/1000 (BOTH), 8/1000 (DL), and 11/1000 (UL); its field-null validity is **not** established (Reviewer A). CSV has 10,800 injected view-level rows and 3,000 null view-level rows, representing 3,600 distinct injection keys, not independent links. Pandas readers must use `keep_default_na=False` to preserve the literal mode label `null`. ## Objections and required repairs

| Objection | Severity | Evidence-based disposition |
|---|---|---|
| Six-variable injection interpreted as RF fade | **Major** | Restrict v12/v21/v23 to algorithmic telemetry stress under frozen morphology. Remove physical-fade or sensitivity-to-natural-degradation interpretation. Historical audit numbers remain valid only for this mathematical family. |
| Encoded MCS treated as interval-valued and perturbed fractionally | **Major** | Document the code mapping from source/vendor; create a separately frozen, physically admissible MCS perturbation or omit MCS from a new analog-only benchmark. Use independent seeds/backgrounds and report the old benchmark alongside the new one; do not silently substitute results. |
| Composite RF outcome called degradation | **Major** | Define it as an operational quality score and RF-event detector, not path loss, attenuation, link availability or throughput. Report component and DL/UL sensitivity; one composite need not track a unique physical failure mode. |
| Operational confounders | **Major for causal reading** | The *analysis snapshot* omits operational columns, but the source export has AP Tx power 10 dBm in 2,860/2,860, SM Tx power 3 dBm in 2,858/2,860, and dual association status in 2,858/2,860. These values are stable in the matched development rows; interference, alignment, maintenance history and path state remain unmeasured. Integrate source covariates with preregistered field eligibility rules; no natural causal claim is authorized. |
| Endpoint weather implies path mechanism | **Major for mechanism claims** | Two station observations do not measure path-integrated rainfall, refractivity or wet-antenna state. ITU-R P.530 treats terrestrial LOS propagation using multiple mechanisms; require link-budget/path evidence for a specific mechanism. |
| One link and one configuration | **Major for transportability** | Quantify performance as conditional on this background; independent links, configuration episodes and natural failures are needed to generalize physical behavior. |

**Disposition after v25:** numerical MCS inadmissibility is explicitly disclosed and a fresh, analog-only direction-specific sensitivity protocol has been executed; some operational covariates have been recovered from the source export. **OPEN (Major)** remains appropriate: 4600-series MCS encoding is unverified; v25 holds MCS fixed and is not a full radio-response model; interference, path weather and independent physical replication are unavailable. Natural propagation and sensitivity claims remain prohibited. Reviewer A remains open, and the pending blinded AI pilot cannot mitigate either audit.
