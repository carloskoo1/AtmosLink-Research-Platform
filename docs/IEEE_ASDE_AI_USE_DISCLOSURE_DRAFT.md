# IEEE ASDE — AI Use Disclosure Draft

**Status:** submission-compliance draft; verify against the current IEEE Access policy immediately before submission.

## Purpose
IEEE Access currently requires disclosure of AI-generated text in the acknowledgements and citation to the AI system in sections that use AI-generated text. The ASDE project has used generative AI materially for scientific criticism, coding assistance, documentation, manuscript drafting/editing, and structured review.

The authors remain responsible for all scientific claims, statistical decisions, code accepted into the repository, references, and final manuscript content.

## Draft acknowledgement language
Generative AI systems were used during the research workflow for code assistance, structured scientific criticism, candidate-interpretation drafting, literature-search support, and language/manuscript editing. AI-generated suggestions did not determine statistical thresholds, alter protected-data boundaries, promote scientific candidates, or replace author review. All analyses, numerical results, citations, code changes, and manuscript claims included in the final article were reviewed and accepted by the human authors.
